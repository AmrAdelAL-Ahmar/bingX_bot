# 🏹 V7Engine.ts — محرك القناص الهجيني متعدد الطبقات

> **الموقع:** `src/core/analysis/engines/V7Engine.ts`  
> **الدور:** محرك تداول متطور وهجين (Multi-Layer Hybrid Sniper) يعتمد على تصفية ثلاثية الأبعاد: إستراتيجية تتبع اتجاه الفريم الأكبر، الشراء/البيع من مناطق السيولة العالية، والاعتماد على زناد دخول تأكيدي ذكي.

---

## 📋 نظرة عامة

| الخاصية | القيمة |
|---------|--------|
| **الابتكار الرئيسي** | خط تصفية رباعي الطبقات (Macro Gate → Meso Gate → Micro Gate → Execution Gate) |
| **التحيز الكلي (Macro)** | دمج SMA50/200 مع اتجاه هيكل السوق اليومي و 4H |
| **مناطق الاهتمام (POI)** | تحديد المنطقة الذهبية فيبوناتشي [0.618 - 0.886] + دمج الكتل OB/FVG |
| **زناد الدخول (Micro)** | تلاقي كسر الهيكل الصغير (MSS) + تشبع وانحرافات RSI (Divergence) |
| **جدار حماية الثقة** | حد أدنى لنسبة نجاح الصفقة **80%** للتنفيذ |

---

## ⚙️ هيكلية الطبقات الأربع (The 4-Layer Pipeline)

يعمل المحرك مثل مصفاة دقيقة للغاية لا تسمح بمرور الصفقات ذات الاحتمالية المنخفضة. يتبع الخطوات التالية للتنفيذ:

```
[ LAYER 1: MACRO GATE ]   --> تحديد التحيز العام (اتجاه صاعد / هابط / حيادي)
         ↓
[ LAYER 2: MESO GATE ]    --> تحديد منطقة الاهتمام الذهبية (Golden Zone) + كتل السيولة OB/FVG
         ↓
[ LAYER 3: MICRO GATE ]   --> انتظار زناد التأكيد اللحظي (MSS Break + Divergence/RSI Extreme)
         ↓
[ LAYER 4: EXECUTION ]    --> احتساب TP/SL ديناميكي + تفعيل جدار الثقة (الحد الأدنى 80%)
```

---

## 🧮 تفاصيل عمل الطبقات

### 1. الطبقة الأولى: MACRO GATE (تحديد التحيز اليومي)
يقوم المحرك بتقييم الفريم اليومي و 4H لتحديد التحيز الكلي:
*   **SMA50 vs SMA200 (التقاطع الذهبي/الموت):** يمنح **30 نقطة** للاتجاه الغالب.
*   **هيكل السوق اليومي (صاعد/هابط):** يمنح **25 نقطة**.
*   **اتجاه SMA20 اليومي:** يمنح **10 نقاط**.
*   **هيكل 4H واتجاهها:** يمنح ما يصل إلى **30 نقطة**.
*   **معيار القرار:** إذا كانت نسبة القوة للصعود $\ge 60\%$ يكون التحيز **LONG**. إذا كانت $\le 40\%$ يكون التحيز **SHORT**. عدا ذلك يكون **NEUTRAL** وتُلغى الصفقة فوراً.

### 2. الطبقة الثانية: MESO GATE (تحديد مناطق الاهتمام POI)
يبحث المحرك في الفريمات المتوسطة (1H أو 15M) عن مستويات سيولة مؤسساتية:
1.  **حساب المنطقة الذهبية (Golden Zone):** يتم حساب مستويات تصحيح فيبوناتشي **[0.618 - 0.886]** من آخر موجة سعرية رئيسية.
2.  **دمج الكتل (Overlap):**
    *   **الأولوية الأولى:** البحث عن كتلة أوامر (Order Block) تتداخل مع المنطقة الذهبية.
    *   **الأولوية الثانية:** البحث عن فجوة قيمة عادلة (Fair Value Gap - FVG) تتداخل مع المنطقة الذهبية.
    *   إذا لم يتواجد السعر داخل هذه المناطق المتداخلة، يوضع البوت في وضع الانتظار (Standby).

### 3. الطبقة الثالثة: MICRO GATE (زناد الدخول التأكيدي)
لتجنب الانعكاس السعري، يتطلب المحرك تأكيداً لحظياً على الفريمات الصغيرة (5M أو 1M):
*   **تشبع RSI:** فحص وصول RSI لمستويات متطرفة (<35 للصعود، >65 للهبوط). (**+25 نقطة**)
*   **انحراف RSI (Divergence):** كشف الانحرافات الإيجابية أو السلبية المؤكدة. (**+30 نقطة**)
*   **كسر الهيكل اللحظي (MSS):** كشف حدوث كسر هيكل حقيقي (Market Structure Shift) على الفريم الصغير. (**+40 نقطة**)
*   **شرط التأكيد:** حدوث كسر الهيكل MSS إلزامي + الحصول على مجموع نقاط $\ge 55$.

### 4. الطبقة الرابعة: EXECUTION GATE (حساب الأهداف وإدارة المخاطر)
*   **وقف الخسارة (SL):** يُحسب أسفل أدنى قاع حديث (أو أعلى قمة حديثة) مطروحاً منه $0.5 \times ATR$، بحد أقصى للمخاطرة **4%** من سعر الدخول.
*   **أخذ الربح (TP):** يتم إسقاط امتداد فيبوناتشي **0.618** من الموجة السابقة، أو حد أدنى $3 \times ATR$.
*   **جدار حماية الثقة:** يتم تجميع نقاط Confluence من جميع الطبقات. إذا كانت نسبة الفوز المحسوبة (WinRate) تقل عن **80%** يتم رفض الصفقة لعدم كفاية التأكيدات.

## 📊 مقارنة V7 مع V6

| الجانب | V6 | V7 |
|--------|----|----|
| **مفهوم الفلترة** | جدار حماية زمني مبسط | تصفية هجينة رباعية الطبقات |
| **هيكل السوق الكلي** | ❌ لا | ✅ فحص الفريم اليومي و 4H |
| **المنطقة الذهبية (Fib)** | ❌ لا | ✅ فحص مستويات 0.618-0.886 |
| **السيولة المؤسساتية (SMC)** | ❌ لا | ✅ كشف وتداخل OB & FVG |
| **زناد الدخول** | فلاتر Divergence بسيطة | كسر هيكل ميكرو MSS + Divergence + RSI |
| **جدار حماية الثقة** | ❌ لا | ✅ تصفية صارمة (WinRate $\ge 80\%$) |
| **تحديد وقف الخسارة** | ATR مبسط | قاع/قمة هيكلية ± ATR هامشي |

## 🎯 متى يتفوق V7؟

1.  **الأسواق ذات الاتجاه الواضح (Trending Markets):** كونه يحترم اتجاه الفريم اليومي بالكامل فلا يدخل عكس التيار.
2.  **مناطق الارتداد القوية:** دمج فيبوناتشي مع OB/FVG يجعله يلتقط القيعان والقمم بدقة متناهية.
3.  **تجنب الاختراقات الكاذبة:** بفضل زناد الـ MSS التأكيدي على فريم 5M/1M.
