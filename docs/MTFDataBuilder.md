# 🏗️ MTFDataBuilder.ts — بناء البيانات متعددة الإطارات

> **الموقع الجديد:** `src/core/shared/MTFDataBuilder.ts`  
> **الدور:** أداة مساعدة لتحويل الإطارات الزمنية ودمج الشمعات. يُستخدم أساساً في `BacktestService` و `BacktestBridgeService` لمنع Look-Ahead Bias والتأكد من إغلاق الشموع التاريخية قبل معالجتها.

---

## 📋 نظرة عامة

يحتوي الكلاس على دالتين ثابتتين (static):
1. `tfToMs` — تحويل اسم الإطار الزمني إلى ميلي ثانية.
2. `aggregateCandles` — دمج شمعات إطار صغير في إطار أكبر.

---

## 🔧 الدوال التفصيلية

---

### 1. `tfToMs(tf: string): number`

**الغرض:** تحويل نص الإطار الزمني (`'5m'`, `'1h'`, `'1d'`...) إلى عدد الميلي ثانية.

**خطوات الحساب:**
```
1. استخراج الرقم:  '5m' → 5 | '1h' → 1 | '4h' → 4
2. استخراج الوحدة: '5m' → 'm' | '1h' → 'h' | '1d' → 'd'
3. ضرب حسب الوحدة:
   m → value × 60 × 1000         (دقائق)
   h → value × 60 × 60 × 1000    (ساعات)
   d → value × 24 × 60 × 60 × 1000 (أيام)
   w → value × 7 × 24 × 60 × 60 × 1000 (أسابيع)
```

**جدول التحويل:**

| الإطار | الميلي ثانية | الوصف |
| :--- | :--- | :--- |
| `1m` | 60,000 | دقيقة واحدة |
| `5m` | 300,000 | 5 دقائق |
| `15m` | 900,000 | ربع ساعة |
| `30m` | 1,800,000 | نصف ساعة |
| `1h` | 3,600,000 | ساعة |
| `4h` | 14,400,000 | 4 ساعات |
| `1d` | 86,400,000 | يوم كامل |

**الاستخدام في BacktestService:**
```typescript
// فلترة الشمعات المغلقة فقط (منع Look-Ahead Bias)
const tfMs = MTFDataBuilder.tfToMs(tf);
const dataUpToT = allData[tf].filter(c => c.timestamp + tfMs <= t);
//                                       ^^^^^^^^^^^^^^^^^^^^^^^^^
//                          الشمعة مغلقة فقط إذا انتهى وقتها قبل اللحظة t
```

---

### 2. `aggregateCandles(baseCandles, targetTF): OHLCV[]`

**الغرض:** دمج (تجميع) شمعات إطار صغير في شمعات إطار أكبر.

**مثال عملي:**
```
12 شمعة × 5m = شمعة 1h واحدة
6 شمعات × 4h = شمعة 1d واحدة
24 شمعة × 1h = شمعة 1d واحدة
```

**قواعد الدمج:**

| الحقل | القيمة |
| :--- | :--- |
| `timestamp` | بداية الفترة (Bucket Time) |
| `open` | سعر فتح أول شمعة في المجموعة |
| `high` | **أعلى** سعر بين جميع شمعات المجموعة |
| `low` | **أدنى** سعر بين جميع شمعات المجموعة |
| `close` | سعر إغلاق آخر شمعة في المجموعة |
| `volume` | **مجموع** حجم التداول لجميع شمعات المجموعة |

**خوارزمية Bucket Time:**
```typescript
// تحديد بداية الفترة الزمنية التي تنتمي إليها الشمعة
const bucketTime = Math.floor(candle.timestamp / targetMs) * targetMs;
```

**مثال توضيحي:**
```
targetMs = 3,600,000 (1h)

شمعة timestamp=09:05 → floor(09:05 / 1h) × 1h = 09:00   ← Bucket 09:00
شمعة timestamp=09:10 → floor(09:10 / 1h) × 1h = 09:00   ← نفس Bucket
شمعة timestamp=09:55 → floor(09:55 / 1h) × 1h = 09:00   ← نفس Bucket
شمعة timestamp=10:00 → floor(10:00 / 1h) × 1h = 10:00   ← Bucket جديد 10:00
```

**تدفق الخوارزمية:**
```
لكل شمعة في baseCandles:
  1. احسب bucketTime
  2. إذا bucket جديد:
     - احفظ الشمعة المجمعة السابقة (إن وجدت)
     - ابدأ شمعة مجمعة جديدة:
         { timestamp: bucketTime, open: candle.open, high, low, close, volume }
  3. إذا نفس bucket:
     - high = max(currentHigh, candle.high)
     - low  = min(currentLow, candle.low)
     - close = candle.close (يُحدَّث باستمرار)
     - volume += candle.volume

بعد الحلقة: احفظ آخر شمعة مجمعة
```

## 🗺️ العلاقة مع باقي النظام

```
MTFDataBuilder
      │
      ├── tfToMs()        ← يستخدمها BacktestService و CoreSniperBacktester
      │       └─ لحساب متى تنتهي الشمعة وتصبح "مغلقة"
      │
      └── aggregateCandles() 
              └─ دمج شموع الفريم الصغير لبناء فريمات أكبر بالذاكرة
```

---

## ⚠️ منع Look-Ahead Bias

في محركات الـ Backtest، يُستخدم `tfToMs` لضمان أن المحرك لا "يرى المستقبل":

```
الشمعة 5m التي تبدأ عند 09:00 → تنتهي عند 09:05
إذا كنا عند t = 09:03 → هذه الشمعة لم تُغلق بعد → لا تُستخدم
إذا كنا عند t = 09:05 → هذه الشمعة أُغلقت الآن → يمكن استخدامها

الشرط: c.timestamp + tfMs(tf) <= t
```

هذا يمنع المحركات من استقاء معلومات مستقبلية في قراراتها، مما يُعطي نتائج واقعية تماماً لصفقات الـ Backtest.
