# 🎛️ الدليل التشغيلي لواجهة التلغرام وضبط الإعدادات الشامل (Telegram Interface & Settings Manual)

> يشرح هذا المستند كل شاشة وأمر وزر في بوت تيليجرام بالتفصيل، موضحاً التأثير الرياضي والميداني لكل إعداد على سلوك التداول، مع تقديم الدليل الذهبي للضبط الموصى به لتحقيق أعلى ربحية وأقل مخاطرة.

---

## 📱 1. دليل الأوامر النصية المباشرة (Slash Commands Reference)

يمكنك كتابة هذه الأوامر مباشرة في شات البوت في أي وقت للوصول الفوري للوظائف:

| الأمر النصي | الوظيفة الميدانية |
| :--- | :--- |
| `/auto` أو `/autonomous` | فتح **لوحة القيادة الرئيسية لمنظومة التداول الذاتي** (عرض الحالة والوضع الحالي). |
| `/aut_settings` | فتح **مركز التحكم بالإعدادات الذاتية** (الدروع، الستوب، الاتجاه، نسب التوافق). |
| `/engines` | فتح **مصفوفة التحكم بالمحركات** (تفعيل أو حظر أي محرك من التحليل والتداول بنقرة واحدة). |
| `/paper` | فتح **لوحة المحفظة الافتراضية** (عرض الرصيد، الربح المحقق PnL، الصفقات المغلقة والنشطة). |
| `/set_paper_balance 1000` | **تصفير السجل الافتراضي** وإعادة ضبط رأس المال الأولي إلى مبلغ محدد (مثلاً 1000$). |
| `/paper_trades` | عرض قائمة **الصفقات الافتراضية النشطة حالياً** مع الأسعار وأرباحها العائمة. |
| `/paper_history` | عرض **سجل الصفقات الافتراضية المغلقة** بالتفصيل وسبب الخروج ونسبة الربح. |
| `/analyze BTC` أو `/math SOL` | فحص فوري معمق للعملة واستخراج ملف التوافق الشامل لجميع المحركات الـ 19. |
| `/status` | فحص حالة الاتصال بالمنصة ورصيد المحفظة الحقيقي ومراقبة التذاكر النشطة. |
| `/heat` | فحص **مستوى حرارة المحفظة الحالية (Portfolio Heat)** ومصفوفة الارتباط بين الصفقات. |
| `/harmonic` | فحص واقتناص نماذج الهارمونيك اللحظية على أفضل العملات. |
| `/macro` | استعراض **المفكرة الاقتصادية العالمية** وتوقيت الأخبار عالية التأثير القادمة. |
| `/circuit_breaker` | فحص وتفعيل قاطع الدائرة لحماية الحساب عند الهبوط الحاد للرصيد. |
| `/panic` | **زر الطوارئ الأحمر:** إغلاق جميع الصفقات المفتوحة فوراً وإلغاء الأوامر المعلقة. |
| `/menu` | إظهار لوحة المفاتيح التفاعلية الرئيسية (Reply Keyboard). |

## ⚙️ 2. شرح شاشة الإعدادات الذاتية بالتفصيل (`/aut_settings`)

عند الدخول إلى لوحة `/aut_settings`، ستجد مجموعة من الأزرار التفاعلية المصممة بعناية:

```
┌────────────────────────────────────────────────────────┐
│  ⚙️ إعدادات منظومة التداول الذاتي المتقدمة (Settings Hub) │
├────────────────────────────────────────────────────────┤
│ 🎮 الوضع: [محاكاة افتراضية (PAPER)]                     │
│ 🔘 الحالة: [✅ مفعل وشغال]                               │
│ 🎯 اتجاه التداول: [LONG ONLY 📈]                        │
│ 📊 شرط التوافق الأدنى: [70%]                            │
│ 🛡️ وضع وقف الخسارة: [ATR_STRUCTURAL 🌊]                │
│ 📏 حدود الستوب: [1.6% - 2.2%]                           │
│ ⚓ حماية الدخول التلقائي: [✅ مفعل عند +0.35%]           │
│ 🎯 قناص التربص: [✅ مفعل (فوليوم 1m)]                   │
│ 🧭 بوصلة البيتكوين: [✅ مفعل (فريم 15m)]               │
│ 🔗 حارس الارتباط: [✅ مفعل (أقصى حرارة 6%)]             │
│ 🤖 تدقيق الذكاء الفائق: [✅ مفعل]                       │
└────────────────────────────────────────────────────────┘
```

### 🔍 تفصيل كل زر وخيار:

#### 1. زر التبديل بين الحقيقي والافتراضي (`aut_toggle_mode`):
* **الخيارات:** `REAL_TRADING` أو `PAPER_TRADING`.
* **التأثير:** يحدد ما إذا كانت الأوامر ستُرسل إلى منصة BingX بأموالك الحقيقية، أم ستُنفذ كصفقات محاكاة فائقة الدقة في المحفظة الافتراضية.

#### 2. زر المفتاح الرئيسي (`aut_toggle_active`):
* **التأثير:** إيقاف أو تشغيل المنظومة الذاتية كلياً بنقرة واحدة. عند الإيقاف، يستمر النظام في مراقبة الصفقات المفتوحة بالفعل لحمايتها دون فتح أي صفقات جديدة.

#### 3. اتجاه التداول المسموح (`aut_set_direction`):
* **الخيارات:**
  - `BOTH 🔄`: السماح بصفقات الشراء والبيع معاً وفق إشارات المحركات.
  - `LONG ONLY 📈` **(موصى به جداً في أسواق الصعود):** يمنع صفقات الـ Short تماماً. أظهر التحليل التجريبي أن صفقات البيع تسببت في $90\%$ من الخسائر الأخيرة نتيجة السباحة ضد تيار البيتكوين الصاعد.
  - `SHORT ONLY 📉`: للمضاربة الهابطة فقط عند دخول السوق في موجة هبوط عامة (Bear Market).

#### 4. شرط التوافق الأدنى (`aut_confluence_min`):
* **الخيارات المتاحة:** `65%` | `70%` | `75%` | `80%` | `85%`.
* **التأثير الرياضي:** يحدد الحد الأدنى من النسبة المئوية المرجحة لأصوات المحركات لإصدار الصفقة.
  - نسبة $70\%$: توازن ممتاز بين عدد الصفقات وجودتها (نحو 2 إلى 5 صفقات في اليوم).
  - نسبة $80\%$: صفقات "قناص نخبوي" شديدة الندرة ذات نسبة فوز قياسية تفوق $85\%$.

#### 5. وضع وقف الخسارة (`aut_toggle_sl_mode`):
* **الخيارات:**
  - `ATR_STRUCTURAL 🌊` **(المعيار الحديث):** يبني الستوب على أدنى قاع أو أعلى قمة لآخر 6 شمعات مضافاً إليه وسادة $0.35 \times ATR$. يمنح الصفقة مساحة للتنفس حتى تصل لأهدافها ويقضي تماماً على حرق الصفقات بالضوضاء.
  - `LEGACY_FIXED 🔒`: النظام القديم ذو الستوب الثابت الضيق ($0.94\%$).

#### 6. حدود الستوب الأدنى والأقصى (`aut_min_sl` & `aut_max_sl`):
* **الحد الأدنى (Min SL):** `1.4%` | `1.6%` | `1.8%` | `2.0%` (يمنع وضع ستوب ضيق يحترق بذيل شمعة عادية).
* **الحد الأقصى (Max SL):** `2.0%` | `2.2%` | `2.5%` | `3.0%` (يمنع تضخم الستوب لحماية رأس المال وحفظ قيمة الرافعة).

#### 7. زر حماية الدخول التلقائي (`aut_toggle_auto_be`):
* **التأثير:** عند تفعيله، يقوم البوت بمراقبة الأرباح؛ فور وصول الربح إلى $+0.35\%$ ينقل الستوب لسعر الدخول $+0.05\%$. هذا الزر بمفرده وفر أكثر من $35$ دولاراً في الباتش التجريبي الأخير.

#### 8. زر محرك التربص (`aut_toggle_stalker`):
* **التأثير:** عند تفعيله، لا يشتري البوت العملة المرتفعة فوراً، بل ينتظر عودتها لمنطقة الارتداد وتأكيد انفجار فوليوم دقيقة $\ge 2\times$.

#### 9. زر بوصلة البيتكوين (`aut_toggle_compass`):
* **التأثير:** يفحص اتجاه البيتكوين ويمنع فتح أي صفقة تسير عكس التيار العام للسيولة الكلية.

#### 10. زر تدقيق الذكاء الفائق (`aut_toggle_gemini`):
* **التأثير:** تفعيل المصادقة البصرية والهيكلية لنموذج Gemini AI قبل اعتماد الصفقة.

## 🧩 3. مصفوفة التحكم بالمحركات وحظرها (`/engines`)

أتاح التحديث الأخير لوحة حصرية لإدارة المحركات الـ 18:

```
┌────────────────────────────────────────────────────────┐
│      👑 مصفوفة التحكم وتفعيل/حظر المحركات التحليلية       │
├────────────────────────────────────────────────────────┤
│ انقر على أي محرك لتفعيله [✅] أو إيقافه وحظره [❌]:     │
│                                                        │
│ [✅ V1]    [❌ V2]    [✅ V3]                          │
│ [❌ V4]    [❌ V5]    [❌ V6]                          │
│ [❌ V7]    [❌ V8]    [❌ V9]                          │
│ [❌ V10]   [✅ V11]   [❌ V12]                         │
│ [❌ V13]   [❌ V14]   [❌ V15]                         │
│ [❌ V16]   [❌ V17]   [❌ V18]                         │
│ [✅ HARMONIC]         [✅ WHALE_SURGE]                 │
├────────────────────────────────────────────────────────┤
│ 👑 تفعيل المحركات الذهبية فقط | 🔄 تفعيل جميع المحركات │
└────────────────────────────────────────────────────────┘
```

### 💡 الأزرار السريعة الذكية (Presets):
1. **زر `👑 تفعيل المحركات الذهبية فقط`:**
   - يقوم فورياً بإبقاء أقوى 4 محركات أثبتت جدارتها في البيانات التجريبية:
     - **V1 (المرجع الأساسي والسيولة اليومية VWAP)**
     - **V11 (المحرك التكيفي لبيئة وترند السوق)**
     - **HARMONIC (قناص النسبة الذهبية ونماذج الهارمونيك 11)**
     - **WHALE_SURGE (كاشف سيولة الحيتان وكسر الهيكل)**
   - ويقوم بحظر باقي المحركات الـ 14 الأخرى بنقرة واحدة لتجنيب المحفظة أي إشارات ضعيفة أو متسرعة حتى يتم صقلها!
2. **زر `🔄 تفعيل جميع المحركات`:**
   - يعيد تفعيل الـ 18 محركاً دفعة واحدة للعمل بنظام الإجماع الكامل.

## 🏆 4. الإعدادات الموصى بها للتشغيل الأمثل (Optimal Profit Settings)

استناداً إلى تحليل الـ 86 صفقة الأخيرة وإحصائيات التعافي المالي، نوصي بضبط الإعدادات كالتالي لتحقيق منحنى أرباح تصاعدي وثابت:

| الإعداد | القيمة الموصى بها | الفائدة الميدانية |
| :--- | :---: | :--- |
| **وضع التداول** | `PAPER_TRADING` (أولاً للاختبار) | اختبار الإعدادات لـ 48 ساعة والتأكد من استقرار الأرباح |
| **اتجاه التداول** | **`LONG ONLY`** | تفادي الشورت المعاكس للتيار وحذف 90% من مسببات الخسارة |
| **مصفوفة المحركات** | **`المحركات الذهبية فقط`** | الاعتماد على V1, V11, HARMONIC, WHALE_SURGE فقط |
| **شرط التوافق الأدنى** | **`75%`** | تصفية الإشارات المتوسطة والاكتفاء بفرص النخبة المؤكدة |
| **وضع وقف الخسارة** | **`ATR_STRUCTURAL`** | منح الصفقة وسادة أمان هيكلية تحت القيعان |
| **حدود الستوب** | **`1.6%` أدنى و `2.2%` أقصى** | القضاء على ضرب الستوب بالضوضاء مع حصر المخاطرة |
| **حماية الدخول (Auto BE)** | **`مفعل (+0.35%)`** | جعل 60% من الصفقات المعاكسة تخرج بتعادل بدون خسارة |
| **محرك التربص (Stalker)** | **`مفعل`** | منع الشراء في القمم والشراء فقط عند إعادة الاختبار بفوليوم دقيقة |
| **بوصلة البيتكوين** | **`مفعل (15m)`** | منع التداول عند وجود نزيف مفاجئ في البيتكوين |
| **حارس الارتباط (Correlation)** | **`مفعل (أقصى حرارة 6%)`** | حظر الدخول في عملات مرتبطة بنفس الاتجاه |
| **تدقيق الذكاء (Gemini)** | **`مفعل`** | مراجعة أخيرة ذكية تلغي الصفقات المشبوهة |

## 🆘 5. بروتوكول التصرف في حالات الطوارئ (Emergency Protocol)

إذا حدثت تقلبات هائلة مفاجئة في السوق (مثل حرب، انهيار منصة، أو خبر كارثي مفاجئ):
1. أرسل الأمر `/panic` فوراً لإغلاق كافة الصفقات المفتوحة وإلغاء أوامر الليمت المعلقة في ثانية واحدة.
2. ادخل إلى `/aut_settings` واضغط على زر `الحالة: [مفعل]` ليتحول إلى `[⏸️ معطل مؤقتاً]`.
3. تابع تحركات السوق عبر `/macro` و `/compass`، وعندما يستقر السعر أعد تفعيل النظام بنقرة زر واحدة.
